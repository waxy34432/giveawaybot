# Giveaway Bot

Бот для проведения розыгрышей с платным участием, обязательной подпиской на 2 канала
и ручной проверкой оплаты админом.

## Установка

    pip install -r requirements.txt

## Настройка

Впишите в config.py:
- BOT_TOKEN: токен от @BotFather
- ADMIN_IDS: ID администраторов (узнать можно у @userinfobot)
- POST_CHANNEL: канал для публикации розыгрышей
- PAYMENT_DETAILS: реквизиты для оплаты

Добавьте бота администратором в оба канала подписки и в POST_CHANNEL.

## Запуск

    python main.py

## Файлы

- main.py: логика бота, хендлеры и FSM
- db.py: работа с SQLite
- config.py: настройки
- requirements.txt: зависимости

## Примечания

- Оплата проверяется админом вручную.
- Номера билетов уникальны в рамках розыгрыша (100000–999999).
- Платные розыгрыши могут подпадать под законы о лотереях и рекламе. Проверьте требования законодательства вашей страны.
