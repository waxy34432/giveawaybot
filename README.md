# Giveaway Bot

Бот для проведения розыгрышей с платным участием, обязательной подпиской на 2 канала
и ручной проверкой оплаты админом.

## Установка

    pip install -r requirements.txt

## Настройка через переменные окружения

Все секреты задаются в панели хостинга (не в коде):

- BOT_TOKEN: токен от @BotFather
- ADMIN_IDS: ID администраторов через запятую (узнать можно у @userinfobot)

Шаблон со всеми переменными лежит в `.env.example`.

Реквизиты для оплаты админ задаёт в боте: кнопка «💳 Реквизиты» в админ-панели.

Для локального запуска можно задать их в терминале или создать `.env`
и загрузить его любым способом, например через python-dotenv.

Добавьте бота администратором в оба канала подписки.

Канал для публикаций админ подключает в боте: кнопка «📢 Канал для публикаций», затем перешлите пост из канала или пришлите его @username. Бот должен быть в канале администратором.

## Запуск

    python main.py

## Файлы

- main.py: логика бота, хендлеры и FSM
- db.py: работа с SQLite
- config.py: чтение настроек из переменных окружения
- requirements.txt: зависимости
- .env.example: шаблон переменных

## Примечания

- Оплата проверяется админом вручную.
- Номера билетов уникальны в рамках розыгрыша (100000–999999).
- Платные розыгрыши могут подпадать под законы о лотереях и рекламе. Проверьте требования законодательства вашей страны.
