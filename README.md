# Giveaway Bot

Бот розыгрышей по образцу @randomized: создание розыгрышей в каналах, несколько победителей,
отложенный старт, завершение по времени или числу участников, капча, буст.
Добавлено: платное участие с чеком и подтверждением админом, ручной выбор победителей.

## Переменные окружения (на хостинге)

- BOT_TOKEN: токен от @BotFather
- ADMIN_IDS: ID администраторов через запятую (узнать у @userinfobot)
- SUPPORT_CONTACT: необязательно, контакт для раздела «Поддержка»
- CLEAN_USER_MESSAGES: необязательно, 1 — бот будет удалять и сообщения самих пользователей
- YOOKASSA_PROVIDER_TOKEN: необязательно, токен ЮKassa из @BotFather (см. раздел «ЮKassa»)
- YOOKASSA_RECEIPT, YOOKASSA_VAT_CODE, YOOKASSA_TAX_SYSTEM: необязательно, данные чека по 54-ФЗ
- DB_PATH: необязательно, путь к файлу базы (укажите путь на постоянном диске хостинга)

Всё остальное (каналы, реквизиты, розыгрыши) настраивается в самом боте.

## Запуск

    pip install -r requirements.txt
    python main.py

## Как пользоваться

1. Добавьте бота администратором в свой канал (или «📢 Мои каналы» → «Добавить по @username»).
2. «💳 Реквизиты» — задайте реквизиты для платных розыгрышей.
3. «➕ Создать розыгрыш» — сначала выберите шаблон (классический, платный, подарок/NFT, деньги, подписка, короткий) и назовите приз: бот сам оформит текст. Либо выберите «Свой текст»: бот отформатирует ваш текст (уберёт лишние пробелы и пустые строки, оформит списки, выделит заголовки) и покажет предпросмотр. Дальше: до 3 фото, цена билета (0 = бесплатно), текст кнопки,
   число победителей, канал публикации, доп. каналы для подписки, время старта (МСК),
   завершение по времени или по числу участников, способ выбора победителей, буст и капча.
4. Платный розыгрыш: участник подписывается на каналы, выбирает число билетов, оплачивает,
   присылает чек и жмёт «Я оплатил». Заявка приходит организатору, после подтверждения
   участнику выдаются случайные номера билетов (больше билетов — больше слотов).
5. Победители: автоматически рандомом или вручную по номерам билетов.
   «🎁 Мои розыгрыши» → розыгрыш → «Участники (CSV)» показывает все билеты.

## Как выглядит пост в канале

Фото и текст выходят одним сообщением. Без фото: текст с кнопкой. Одно фото: фото с подписью и кнопкой.
2–3 фото: альбом с подписью и кликабельной ссылкой «Участвовать» (Telegram не позволяет ставить кнопки
под альбомом). Подпись к фото ограничена Telegram примерно 1000 символов: если текст с условиями длиннее,
бот предложит сократить текст или убрать фото.

## ЮKassa

Оплата картой прямо в Telegram через платежи Telegram с провайдером ЮKassa. Билеты выдаются автоматически
сразу после оплаты, подтверждать заявки вручную не нужно.

Подключение:
1. В @BotFather: ваш бот → Bot Settings → Payments → ЮKassa. Сначала подключите тестовый магазин.
2. BotFather выдаст токен провайдера. Задайте его на хостинге как YOOKASSA_PROVIDER_TOKEN и перезапустите бота.
3. Если ваш магазин в ЮKassa работает с чеками по 54-ФЗ, добавьте YOOKASSA_RECEIPT=1 и при необходимости
   YOOKASSA_VAT_CODE и YOOKASSA_TAX_SYSTEM. Бот тогда запросит e-mail покупателя и передаст данные чека.
4. Проверьте тестовым платежом (тестовые карты есть в документации ЮKassa), затем подключайте боевой магазин.

При создании платного розыгрыша появится шаг «Как участники будут платить»: ЮKassa, реквизиты с чеком или оба
способа на выбор участника. Без токена этот шаг не показывается, работают реквизиты.

Важно:
- Возвраты делаются в личном кабинете ЮKassa вручную. Если платёж пришёл после закрытия приёма участников,
  билеты не выдаются, а организатору приходит уведомление с ID платежа.
- Платное участие в розыгрыше с призом могут считать лотереей. Правила платёжных сервисов и закон обычно
  ограничивают такую деятельность. Перед боевым подключением уточните у поддержки ЮKassa, разрешён ли ваш формат.

## Навигация

В каждом разделе есть кнопки возврата. «🏠 Главное меню» (или «🏠 Меню») сбрасывает текущий сценарий и
открывает главное меню. «⬅️ Назад» возвращает на предыдущий экран: при создании розыгрыша на предыдущий шаг
(введённые данные сохраняются), в карточке розыгрыша к списку, в списке каналов и в ручном выборе
победителей на предыдущий экран. Участникам доступны «⬅️ Назад» на экранах оплаты и чека и «🏠 В начало».

## Режим «одно сообщение»

В личных чатах каждое новое сообщение бота заменяет предыдущее (по нажатию кнопки или после любого
текста, фото, видео). Не удаляются: заявки на оплату, номера билетов, уведомления о результатах,
CSV с участниками и посты в каналах.

## Файлы

- main.py: логика бота
- db.py: SQLite
- cleanchat.py: замена предыдущего сообщения новым
- logic.py: время, выбор победителей, автоформат текста
- templates.py: шаблоны розыгрышей (их можно редактировать)
- config.py: чтение переменных окружения

## Важно

- Бот должен быть администратором во всех каналах из условий подписки, иначе подписку не проверить.
- Время указывается по Москве.
- Файл базы лежит на диске. Если хостинг стирает файлы при деплое, подключите постоянный диск и укажите DB_PATH.
- Платные розыгрыши могут подпадать под законы о лотереях и рекламе. Проверьте требования вашей страны.
